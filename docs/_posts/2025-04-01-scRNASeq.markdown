# Quick Summary
* Built the **first transcriptional atlas** for L1 larval stage in nematode *C. elegans* using **scRNASeq**

* Investigated **starvation-response** at cellular level for the first time in any animal using **scRANSeq and DE analysis**

* Built a [Web Tool][l1_sc] for users to query their favorite gene in starvation response across cell types

* Developed a novel **"voting" algorithm** to determine optimally extended 3' UTRome

# Motivation
  Virtually all animals adjust their behavior in response to changes in nutrient availability.

![Nutrient availibility ~ behavior]({{ '/assets/images/nutrient_and_behavior.png' | relative_url }}){: style="width:auto; height:300px;" }

But that behavior is a whole-animal outcome of cellular responses. It would be simple-minded to assume all cells respond the same way. To really understand what's happening, we need a high-resolution view of how different cells react—and that's where **single-cell RNA-seq (scRNASeq)** comes in.

# Thought Process And Results
### What model organism to choose?
We need something whose behavior is **robustly regulated** by nutrient availibility changes. The first thing that came into mind was the [dauer][dauer] stage of *C. elegans*, which is triggered when worms are short of food. **However**, dauer is triggered by some other cues as well, like high temperature and overcrowed poopulation, which might very likely confound their response to purely "nutrient availibility".

Is there a biological context that's ONLY and rosbustly triggered by nutrient availibility? Turns out yes—the first larval stage (L1) of *C. elegans*. When worms hatch with food, they become an L1; when they hatch without food, they inevitably enter "L1 arrest", where no development occurs and they focus on "survival".
